# Security Toolkit

A Python-based security analysis toolkit containing ten modules for network, web, URL, DNS, HTTP, TLS, and hash analysis.

## Modules

1. **Port Scanner** — Checks port reachability on authorized targets.
2. **Hash Analyzer** — Analyzes cryptographic hashes.
3. **HTTP Security Checker** — Checks HTTP security-related configuration.
4. **Web Security Analyzer** — Performs implemented web security checks.
5. **DNS Analyzer** — Examines DNS information.
6. **Network Information** — Collects network-related information.
7. **URL Analyzer** — Analyzes URL components.
8. **TLS / Certificate Analyzer** — Inspects TLS and certificate information.
9. **HTTP Redirect Analyzer** — Examines HTTP redirect behavior.
10. **Cookie Security Analyzer** — Checks cookie security attributes.

## Responsible Use

Use this toolkit only on systems you own or have explicit permission to test.

- Do not test systems without authorization.
- Do not expose credentials, private keys, or sensitive scan results.
- Treat findings as indicators for investigation, not guarantees of security.
